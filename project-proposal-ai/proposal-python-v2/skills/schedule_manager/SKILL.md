# 进度计划确认（V2）

> ⚠️ 本技能为 V2 预留，当前版本不启用。

## 功能概述

根据立项批复日期和项目周期，自动生成进度计划里程碑及其开始/结束时间。

## 核心规则（V2待实现）

- 里程碑名称：需求分析、开发测试、上线发布
- 时间计算：基于立项批复日 + 项目周期推算
- 支持手动调整日期

## 可用工具（V2待注册）

- get_schedule — 获取进度计划
- update_schedule — 更新里程碑日期
