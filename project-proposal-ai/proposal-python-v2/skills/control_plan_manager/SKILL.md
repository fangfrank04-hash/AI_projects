# 管控方案确认（V2）

> ⚠️ 本技能为 V2 预留，当前版本不启用。

## 功能概述

根据项目级别（S/A/B/C）和研发工艺要求，自动确定各阶段的剪裁结果。

## 核心规则（V2待实现）

- 需求阶段：视项目类型决定
- 开发阶段：**不可裁剪**
- 测试阶段：**不可裁剪**
- 项目评审：S级必须，其他可选
- 结项阶段：必须

## 可用工具（V2待注册）

- get_phase_activities — 获取阶段活动列表
- update_cut_result — 更新剪裁结果
