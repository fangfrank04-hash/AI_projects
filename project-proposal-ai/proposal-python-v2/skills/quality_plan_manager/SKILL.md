# 质量保证计划确认（V2）

> ⚠️ 本技能为 V2 预留，当前版本不启用。

## 功能概述

根据项目级别自动生成质量保证计划，包括质量目标、评审机制、测试策略和质量指标。

## 核心规则（V2待实现）

- 质量目标：缺陷密度、测试覆盖率、评审通过率
- 评审机制：需求评审、设计评审、代码评审、测试用例评审
- 测试策略：单元测试、集成测试、系统测试（S级加安全测试和UAT）
- 质量指标：缺陷密度、测试覆盖率、代码评审率

## 可用工具（V2待注册）

- get_quality_plan — 获取质量保证计划
- update_quality_plan — 更新质量数据
