### 1.2 FastAPI + agentscope 集成方式

**核心思路**：FastAPI负责HTTP层和SSE流式传输，agentscope负责AI Agent编排和工具调用。两者通过异步队列（asyncio.Queue）解耦。

```python
# main.py 核心结构
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from agent_setup import ProjectAssistantAgent
import asyncio

app = FastAPI()
agent_pool = {}  # session_id -> agent实例

@app.get("/api/chat/stream")
async def chat_stream(projectId: str, userName: str, isPM: bool):
    queue = asyncio.Queue()
    agent = await create_agent(projectId, userName, isPM, queue)
    agent_pool[agent.session_id] = agent
    
    async def event_generator():
        while True:
            msg = await queue.get()
            if msg["event"] == "close":
                break
            yield format_sse(msg)
    
    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

**agentscope集成细节**：
- ReActAgent在初始化时注入 `queue` 对象，Agent内部通过 `queue.put()` 推送SSE事件
- Toolkit同时注册MCP Client和本地Skill，Agent决策时自动选择工具
- DashScopeChatModel配置 `stream=True` 时，模型输出通过回调写入queue

### 1.3 SSE流式输出实现方案

**方案选择**：FastAPI原生 `StreamingResponse` + `asyncio.Queue` 生产者-消费者模式。

**为什么不用agentscope内置Server？**
- agentscope内置Server为通用Agent对话设计，不符合本项目"事件驱动型SSE"需求
- 本项目SSE需要发送多种事件类型（text / update_project / update_team / fillback_complete），并非纯文本流
- 自定义Queue方式更灵活，可精确控制每条SSE的事件名和数据结构

**SSE事件格式**：
```
event: text\ndata: {"content": "您好"}\n\n
event: update_project\ndata: {"projectData": {"productNo": "ABC-001"}}\n\n
event: ping\ndata: {"time": 1715068800}\n\n
```

**心跳机制**：后台协程每30秒向queue写入 `{"event": "ping", "data": {...}}`。

**重连机制**：前端EventSource断开时自动重连，指数退避（1s / 2s / 4s），最多3次。重连时携带相同sessionId，后台复用agent实例。

### 1.4 MCP Server设计（Streamable HTTP）

**传输协议**：采用 MCP 2025-06-18 规范的 Streamable HTTP 传输。
- 单一端点 `/mcp` 同时支持 POST（发送请求）、GET（SSE 流）、DELETE（终止会话）
- Session 管理通过 `Mcp-Session-Id` 请求头实现
- MCP Server 作为**独立进程**运行在端口 8001，与 FastAPI（端口 8000）分离

**本地开发策略**：
- `DEV_MODE=true` 时不连接真实 Java 服务，直接返回 `mock_data.py` 中的数据
- `DEV_MODE=false` 时通过 `java_client.py` 调用 Java 服务（默认 `http://localhost:8088`）

**技术选型**：官方 `mcp` Python SDK（`>=1.8.0`），原生支持 `transport="streamable-http"`。

```python
# mcp_server/server.py 核心结构
from mcp.server.fastmcp import FastMCP
from java_client import JavaClient
from mock_data import MOCK_PROJECT, MOCK_TEAM
import os

mcp = FastMCP("zhongzhai_java_gateway")
java_client = JavaClient()
DEV_MODE = os.getenv("DEV_MODE", "false").lower() == "true"

@mcp.tool()
async def get_project_info(id: str) -> list:
    """查询项目基本信息"""
    if DEV_MODE:
        return [TextContent(type="text", text=json.dumps(MOCK_PROJECT))]
    result = await java_client.safe_invoke(
        "/itmp/pmProjectService/findProjectById", {"id": id}
    )
    return [TextContent(type="text", text=json.dumps(result))]

@mcp.tool()
async def get_team_members(pmProjectId: str, page: int = 0, size: int = 10) -> list:
    """查询项目团队成员"""
    if DEV_MODE:
        return [TextContent(type="text", text=json.dumps(MOCK_TEAM))]
    result = await java_client.safe_invoke(
        "/itmp/pmProjectMemberService/findPmProjectMemberList",
        {"pmProjectId": pmProjectId, "pageable": {"page": page, "size": size}}
    )
    return [TextContent(type="text", text=json.dumps(result))]

# ... update_project / add_members / delete_members / update_member_roles / update_duty / get_user_by_id

if __name__ == "__main__":
    mcp.run(
        transport="streamable-http",
        host=os.getenv("MCP_HOST", "127.0.0.1"),
        port=int(os.getenv("MCP_PORT", "8001")),
        path="/mcp"
    )
```

**MCP工具命名约定**：采用下划线命名，与Python函数名一致，便于agentscope自动映射。

**错误处理**：Java 超时返回 `-32000`，Java 500 返回 `-32603`，Java 404 返回 `-32602`，详见 `05-MCP服务设计文档.md`。

### 1.5 Skill加载机制

**Skill用途**：封装"团队职责维护"的业务规则，使Agent能根据规则判断职责合法性、生成职责列表等。

**加载方式**：
```python
# agent_setup.py
from agentscope.tool import Toolkit
from mcp.client.streamable_http import streamablehttp_client
from mcp import ClientSession
import os

toolkit = Toolkit()
MCP_SERVER_URL = os.getenv("MCP_SERVER_URL", "http://127.0.0.1:8001/mcp")

# 1. 注册MCP工具（数据操作）
async with streamablehttp_client(MCP_SERVER_URL) as (read_stream, write_stream, get_session_id):
    async with ClientSession(read_stream, write_stream) as session:
        await session.initialize()
        tools_result = await session.list_tools()
        toolkit.register_mcp_tools(tools_result.tools, session)

# 2. 注册本地Skill（业务规则）
toolkit.register_agent_skill("skills/team_duty_manager")

# SKILL.md 内部可定义工具函数，例如：
# - get_available_duties(role: str) -> list  (返回某角色可选职责)
# - validate_duty_change(role: str, duty: str, action: str) -> bool  (校验职责变更是否合法)
```

**SKILL.md结构**：遵循agentscope Skill规范，包含函数定义、描述（docstring将作为Tool描述传入LLM）、参数类型注解。

    draft_team: list          # 团队职责草稿

# 初始化流程
async def create_agent(project_id, user_name, is_pm, queue) -> ProjectAssistantAgent:
    # 1. 加载配置
    # 2. 创建Toolkit并注册MCP Client + Skill
    # 3. 创建ReActAgent（注入sys_prompt、model、memory、toolkit）
    # 4. 调用MCP获取初始数据 → draft_project / draft_team

**SysPrompt设计要点**：
- 明确告知Agent当前用户身份（是否PM），决定可编辑字段

### 3.4 SSE消息数据结构

```typescript
// TypeScript类型定义（前后端共享约定）

interface SSEEvent {
    event: "connected" | "preview" | "text" | "update_project" | "update_team" | "fillback_complete" | "error" | "ping";
    data: SSEEventData;
}

interface ConnectedEvent {
    sessionId: string;
    status: "ok";
}

interface PreviewEvent {
    projectData: ProjectData;
    teamData: TeamMember[];
}

interface TextEvent {
    content: string;  // AI自然语言回复文本（支持逐字流式）
}

interface UpdateProjectEvent {
    projectData: ProjectData;  // 完整项目信息快照
}

interface UpdateTeamEvent {
    teamData: TeamMember[];    // 完整团队列表快照
}

interface FillbackCompleteEvent {
    success: boolean;
    message: string;
}

interface ErrorEvent {
    message: string;
    code?: string;
}

interface PingEvent {
    time: number;  // Unix timestamp
}

// 核心数据模型
interface ProjectData {
    id: string;           // 项目编号
    name: string;         // 项目名称
    dept: string;         // 立项申请部门
    baseReq: string;      // 基准需求编号
    level: string;        // S级/A级/B级/C级
    productNo: string;    // 产品编号（可编辑）
    productName: string;  // 产品名称（可编辑）
    reqDept: string;      // 需求相关部门
    changeReq: string;    // 变更需求编号
    pmName: string;       // 项目经理姓名
}

interface TeamMember {
    role: string;                     // 项目角色
    name: string;                     // 人员姓名
    responsibilities: Responsibility[]; // 职责列表
}

interface Responsibility {
    name: string;
    checked: boolean;
}
```
