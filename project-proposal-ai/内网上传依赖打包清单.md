# 项目依赖打包清单 — PyCharm 小白操作指南

> 更新时间：2026-05-20  
> 版本：Python 3.12 专用（匹配内网环境）  
> 目标：把依赖文件直接复制到内网的虚拟环境里，不用 pip、不用联网

---

## 0. 三个概念，先搞清楚

| 词 | 是什么 | 你的内网位置 |
|---|--------|-------------|
| **Python 解释器** | 运行 Python 代码的程序 | `D:\pyvenv\KBM\Scripts\python.exe` |
| **虚拟环境** | 隔离的 Python 房间，每个项目独立 | `D:\pyvenv\KBM\` |
| **site-packages** | 房间里的仓库，放所有依赖包 | `D:\pyvenv\KBM\Lib\site-packages\` |

**简单比喻**：虚拟环境 = 厨房，解释器 = 灶台，site-packages = 调料柜。你要做菜（运行代码），调料（依赖包）得放在调料柜（site-packages）里。

## 1. 依赖文件在哪里

打开项目根目录下的 **「项目依赖」** 文件夹：

```
项目依赖/
├── Python依赖/    ← 已经全部就绪：249项（包文件夹 + 元数据），Python 3.12 版本 ✅
├── 前端依赖/      ← node_modules 文件夹，85MB ✅
└── Java依赖/      ← 需要额外处理（见第4节）
```

### 🔑 Python依赖 里的东西怎么看

打开 `项目依赖/Python依赖/`，你会看到：

```
fastapi/              ← 这就是一个包，里面是 .py 和 .pyd 文件
fastapi-0.136.1.dist-info/   ← 这个包的"身份证"（版本信息）
numpy/                ← numpy 包
grpc/                 ← grpc 包
typing_extensions.py  ← 有些包只有一个 .py 文件
...
```

和内网 `D:\pyvenv\KBM\Lib\site-packages\` 里面的东西**格式一模一样**。

## 2. Python — 怎么把依赖装到内网虚拟环境

### 2.1 操作方法（复制粘贴就完事）

**你的内网路径**（从图片确认的）：`D:\pyvenv\KBM\`

**步骤**：

1. 打开 `项目依赖/Python依赖/`，**Ctrl+A 全选**所有文件和文件夹
2. **Ctrl+C 复制**
3. 打开内网的 `D:\pyvenv\KBM\Lib\site-packages\`
4. **Ctrl+V 粘贴**，遇到"是否覆盖"提示，选**「是」**或**「全部覆盖」**

> ⚠️ 注意：是放到 `Lib\site-packages\` 里面，不是放到 `Lib\` 外面！

### 2.2 启动 Python 后台

1. 在 PyCharm 打开本项目
2. PyCharm 右下角确保选择了正确的解释器：`D:\pyvenv\KBM\Scripts\python.exe`
3. 打开 `proposal-python-v2/main.py`
4. 右键 → **Run 'main'**（或点右上角绿色▶️）

看到 `Uvicorn running on http://127.0.0.1:8000` 就成功了。

### 2.3 如果报错

| 现象 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: No module named 'xxx'` | 复制漏了/位置放错了 | 确认复制到了 `Lib\site-packages\` 里面 |
| `ImportError: DLL load failed` | 复制过程中文件损坏或版本不对 | 重新复制一次 |
| 解释器没找到 | PyCharm 没选对解释器 | 右下角点 Python 版本 → 选择 `D:\pyvenv\KBM\Scripts\python.exe` |

## 3. 前端（React）— 配置和启动

### 3.1 恢复 node_modules

前端依赖已经放在 `项目依赖/前端依赖/node_modules`。

把 `node_modules` 文件夹**复制到** `react-frontend/` 目录下面，变成 `react-frontend/node_modules/`。

### 3.2 启动

在 PyCharm 底部 Terminal：

```
cd react-frontend
npm run dev
```

浏览器访问 `http://localhost:5173/`。

---

## 4. Java 后台 — 配置和启动

### 4.1 需要 JDK 17

当前开发机只有 JDK 1.6，无法构建 Java 项目。需要在一台有 JDK 17+ 的电脑上执行以下步骤：

**如果你能找到 JDK 17 的电脑**：

```
cd proposal-java
mvn clean package -DskipTests
```

生成的 `target/proposal-ai-service-1.0.0.jar` 放到 `项目依赖/Java依赖/`。

启动：
```
java -jar 项目依赖\Java依赖\proposal-ai-service-1.0.0.jar
```

### 4.2 如果没有 JDK 17 电脑

把 `项目依赖/Java依赖/README.txt` 给公司后台同事，让他们帮忙打一个 jar 包给你。
