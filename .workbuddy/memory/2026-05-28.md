## 2026-05-28

### Java Cookie 认证支持
- 在 `mcp_server/config.py` 新增 `JAVA_COOKIE` 配置项
- 在 `mcp_server/java_client.py` 的 `JavaHttpClient.__init__` 中添加 Cookie header
- 在 `.env` 添加 `JAVA_SERVICE_URL` 和 `JAVA_COOKIE` 占位项

### 接 Java 的完整步骤
1. 浏览器登录内网 → F12 → Application → Cookies → 复制完整 cookie 串
2. `.env` 设置 `DEV_MODE=false`，`JAVA_COOKIE=粘贴的cookie`
3. `.env` 设置 `JAVA_SERVICE_URL=http://同事IP:8088`
4. 重启 MCP Server，看到 `[JavaClient] Cookie 已配置` 即成功
