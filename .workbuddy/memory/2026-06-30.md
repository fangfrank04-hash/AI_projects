## 领导关于连接方式统一的问题分析

### 完成内容
- 读取 main.py 并确认当前项目同时存在两种连接方式：
  - 方式1/2：SSE 长连接模式（/api/chat/stream + /api/chat/message + /api/chat/fillback）

- 分析了领导"一体化用SSE，之前两个用单次，是否需要统一"的含义

### 关键发现

- 模式3前端更友好（普通 fetch + ReadableStream），无需 EventSource 的 session 生命周期管理
- 保留 fillback-v3 可以在无 session 状态下完成一键回填
