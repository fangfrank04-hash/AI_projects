## 2026-05-27

### 项目启动
- 按顺序启动全部3个服务：MCP(8001) → FastAPI(8000) → React前端(5173)
- 使用独立PowerShell窗口运行（避免后台任务超时被kill）

### 依赖处理
- 项目设计为 Python 3.12 + venv 在 D:\pyvenv\KBM\
- 实际使用 Python 3.13.12，创建新 venv: `proposal-python-v2\.venv`
- agentscope 必须用 1.0.20（非 2.x），否则 ReActAgent import 失败
- ripgrep 需 `--only-binary :all:` 避免 MSVC 编译
- 安装命令：
  ```
  pip install fastapi "uvicorn[standard]" mcp httpx pydantic python-dotenv
  pip install "ripgrep" --only-binary :all:
  pip install "agentscope==1.0.20"
  ```

### 已知问题
- 0.0.0.0:8000 被 Windows 端口排除/占用，需用 127.0.0.1:8000
- bash 后台任务有超时限制，长驻服务需用 PowerShell Start-Process -NoExit
