## 2026-06-24

### Cookie 动态认证改造
- **目标**: 将 JAVA_COOKIE 从"启动时读 .env 固定死"改为"运行时可动态更新"
- **方案**: Java 后台通过 `POST /api/auth/set-cookie` 推送 Cookie 给 Python，存内存缓存
- **改动文件**:
  - `proposal-python-v2/mcp_server/config.py`: 新增 `_cookie_cache` + `set_cookie()` / `get_cookie()` / `clear_cookie()`
  - `proposal-python-v2/mcp_server/java_client.py`: `__init__` 不固定 headers，`call()`/`call_direct()` 每次动态取 Cookie，检测 401 清缓存
  - `proposal-python-v2/main.py`: 新增 `POST /api/auth/set-cookie` 接口
- **降级策略**: `.env` 的 `JAVA_COOKIE` 保留作为兜底（缓存为空时使用）
- **后续**: 需要前端点击 AI 聊天窗口时调 Java，Java 再调 `/api/auth/set-cookie` 推送 Cookie
