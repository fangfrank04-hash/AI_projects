# 测试照片标准答案表设计

## 目标

为测试照片建立一份明确、可检查的标准答案表。测试程序不再根据文件名临时猜答案，而是读取答案表，将识别结果与标准答案逐张比较。

第一阶段只整理测试标准和测试工具，不调整 MediaPipe 模型、识别阈值或业务判断逻辑。

## 照片范围

正式主测试集包含 305 张原始照片：

- `assets/test_images/samples_v2`：180 张。
- `assets/test_images/targeted_samples`：125 张。

以下照片不重复计入 305 张主测试集：

- `samples_v2_annotated` 和 `samples_annotated`：带标注的衍生副本。
- `targeted_samples_clean`：从 `targeted_samples` 复制整理出的子集。

以下照片单独作为补充测试，不与 305 张主测试集混算：

- `ai_generated`：30 张挑战图片。
- `samples`：14 张旧版真实图片。
- 项目内其他单张示例图片，除非以后明确加入答案表。

原始照片不删除。需要排除的照片仍保留，并在答案表中记录排除原因。

## 标准答案表

新增 `assets/test_images/test_answers.csv`，每张纳入管理的原始照片占一行。至少记录：

- 照片路径。
- 来源数据集。
- 拍摄场景。
- 正确告警类别。
- 用于调规则还是最终检查。
- 是否计入主测试成绩。
- 排除原因或特殊说明。

照片路径是唯一标识。程序发现同一路径重复、照片不存在、答案为空或答案类别不合法时，应停止测试并指出具体问题，不能静默跳过。

## 已确认的判定标准

系统最终按以下 6 类统计：正常考试、视线偏移、离开座位、多人、打电话、伸胳膊。

- 正常坐姿、正视或允许范围内的轻微自然动作：正常考试。
- 低头写字：视线偏移，必须告警。
- 低头看手机：视线偏移。
- 坐在座位上转头、转身、侧身或背向镜头：视线偏移。
- 站起来，即使仍在画面中：离开座位。
- 人完全不在画面中：离开座位。
- 确认出现第二个人，包括只露出一部分或从背后经过：多人。
- 明确举手机贴近耳边：打电话。
- 明确伸展单臂或双臂：伸胳膊。

## 测试方式

测试流程如下：

1. 读取标准答案表并检查答案表本身是否完整、是否重复。
2. 只读取答案表指定的原始照片，避免把复制图片重复计算。
3. 对每张照片运行一次现有识别逻辑。
4. 识别类别与标准答案一致才算通过，不再允许“视线偏移识别成正常也算通过”。
5. 输出逐张明细、各类别结果和总体结果。

报告必须单独显示正常考试的误报情况。后续调整识别规则时，正常考试的误报表现是最高优先保护项，不能只看总体准确率。

`targeted_samples` 现有的调试组和检查组来自同一批连续拍摄照片，因此只能说明同一场景下是否稳定，不能宣称代表陌生考场中的泛化能力。报告中要明确这一点。

## 验收标准

第一阶段完成时应满足：

- 305 张主测试照片每张都有且只有一个答案。
- 3 张“坐着转身”照片被标为视线偏移并参与统计。
- 衍生副本不会重复计分。
- 低头写字和低头看手机识别成正常时必须判错。
- 坐着转头或转身识别成离开座位时必须判错。
- 缺照片、重复答案或非法答案会明确报错。
- 报告分别给出每一类成绩和正常考试误报情况。
- 旧的 83.61% 只作为历史参考，使用新答案表后重新生成严格成绩。

## 暂不处理

- 不新增 YOLO 或其他模型。
- 不要求重拍照片。
- 不在第一阶段调整识别阈值和业务规则。
- 不在第一阶段修改并发控制。
- 不把补充测试集结果混入 305 张主测试集成绩。
