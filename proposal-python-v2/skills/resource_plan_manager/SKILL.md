# 资源计划确认（V2）

> ⚠️ 本技能为 V2 预留，当前版本不启用。

## 功能概述

根据项目规模和团队配置，自动生成资源计划，包括总工作量、自有人员工作量、外包工作量等。

## 核心规则（V2待实现）

- 总工作量(人天) = 自有 + 人员外包 + 项目外包
- 总工期(天) 基于里程碑跨度计算
- 按角色分配人员投入工作量

## 可用工具（V2待注册）

- get_resource_plan — 获取资源计划
- update_resource_plan — 更新资源数据
