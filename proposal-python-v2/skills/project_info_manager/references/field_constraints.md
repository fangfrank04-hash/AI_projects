# 字段约束详细说明

本文档详细说明项目基本信息和团队成员各字段的约束规则。

## 项目基本信息字段约束

### 可编辑字段（白名单）

#### 1. productCode（产品编号）

**字段类型**：string

**编辑权限**：
- ✅ 只有 `isPM=true` 的用户可以编辑
- ❌ 其他用户只能查看

**格式约束**：
- 推荐格式：`[A-Z]{2,}-\d{4}-\d{3}`（如：ABC-2026-001）
- 允许任意字符串，但建议遵循命名规范

**示例**：
```
✅ 有效值：
- ABC-2026-001
- PROD-2026-042
- XYZ-2025-123

❌ 不推荐值（但可以保存）：
- 新产品
- 2026年项目
- 测试
```

**修改示例**：
```python
# 修改产品编号
result = await update_project_info(
    project_id="P001",
    productCode="ABC-2026-001"
)
```

---

#### 2. productName（产品名称）

**字段类型**：string

**编辑权限**：
- ✅ 只有 `isPM=true` 的用户可以编辑
- ❌ 其他用户只能查看

**格式约束**：
- 允许任意字符串
- 建议简洁、 descriptive

**示例**：
```
✅ 有效值：
- 核心业务系统V2.0
- 客户关系管理平台
- 数据可视化分析系统

❌ 不推荐值：
-  undefined
-  null
- （空字符串）
```

**修改示例**：
```python
# 修改产品名称
result = await update_project_info(
    project_id="P001",
    productName="核心业务系统V2.0"
)
```

---

### 不可编辑字段（黑名单）

以下字段**不可通过AI助手修改**，如果尝试修改会被拦截：

#### 1. id（项目ID）

**字段类型**：string

**不可编辑原因**：项目唯一标识符，修改会破坏数据关联

**拦截话术**：
```
💡 抱歉，系统规定【项目ID】不可修改。如需修改，请联系管理员。
```

---

#### 2. name（项目名称）

**字段类型**：string

**不可编辑原因**：项目名称由立项流程确定，不在方案书填写阶段修改

**拦截话术**：
```
💡 抱歉，系统规定除【产品编号】和【产品名称】外，其他项目基本信息不可在此修改。如需修改，请联系管理员。
```

---

#### 3. dept（立项申请部门）

**字段类型**：string

**不可编辑原因**：立项部门由审批流程确定

**拦截话术**：同上

---

#### 4. level（项目级别）

**字段类型**：string（枚举值：S/A/B/C）

**不可编辑原因**：项目级别由PMO评定

**拦截话术**：同上

---

#### 5. baseReq（基准需求编号）

**字段类型**：string

**不可编辑原因**：基准需求编号由需求管理系统同步

**拦截话术**：同上

---

#### 6. reqDept（需求相关部门）

**字段类型**：string

**不可编辑原因**：需求部门由需求管理系统同步

**拦截话术**：同上

---

#### 7. changeReq（变更需求编号）

**字段类型**：string

**不可编辑原因**：变更需求编号由变更管理流程确定

**拦截话术**：同上

---

#### 8. pmName（项目经理姓名）

**字段类型**：string

**不可编辑原因**：项目经理由资源管理系统分配

**拦截话术**：同上

---

## 团队成员字段约束

### 可编辑字段

#### 1. responsibilities（职责）

**字段类型**：object（字典）

**结构**：
```json
{
  "需求评审": true,
  "产品设计": false,
  "开发排期": true,
  "测试验收": false,
  "产品发布": true
}
```

**编辑权限**：
- ✅ 只有 `isPM=true` 的用户可以编辑
- ❌ 其他用户只能查看

**可选职责列表**：
- 需求评审
- 产品设计
- 开发排期
- 测试验收
- 产品发布

**修改示例**：
```python
# 勾选职责
result = await update_member_duty(
    project_id="P001",
    name="张三",
    duty_name="需求评审",
    checked=True
)

# 取消职责
result = await update_member_duty(
    project_id="P001",
    name="张三",
    duty_name="需求评审",
    checked=False
)
```

---

### 不可编辑字段

#### 1. name（成员姓名）

**字段类型**：string

**不可编辑原因**：成员姓名由系统维护，不支持修改

**注意事项**：
- 如果需要修改成员姓名，应该先删除旧成员，再添加新成员
- 前端表格中 `name` 字段不可编辑

**错误话术**：
```
💡 抱歉，成员姓名由系统维护，不可在此修改。如需修改，请删除旧成员后重新添加。
```

---

#### 2. role（成员角色）

**字段类型**：string

**不可编辑原因**：成员角色由系统维护

**注意事项**：
- 前端表格中 `role` 字段不可编辑
- 如果需要修改成员角色，应该先删除旧成员，再添加新角色的成员

**错误话术**：
```
💡 抱歉，成员角色由系统维护，不可在此修改。如需修改，请删除旧成员后重新添加。
```

---

## 字段验证规则

### 通用验证规则

1. **非空验证**：
   - `project_id` 不能为空
   - `name`（成员姓名）不能为空
   - `role`（成员角色）不能为空

2. **格式验证**：
   - `productCode` 建议遵循命名规范（但不强制）
   - `productName` 不能为空字符串

3. **权限验证**：
   - 所有写操作必须检查 `isPM` 标志
   - 如果 `isPM=false`，返回权限拒绝错误

## 错误示例和正确处理

### 错误示例1：尝试修改不可编辑字段

**用户指令**：
```
把项目名称改成"新核心系统"
```

**AI处理逻辑**：
1. 解析意图：类型A — 修改项目基本信息
2. 检查字段白名单：`name`（项目名称）不在白名单中
3. 拦截并回复：
```
💡 抱歉，系统规定除【产品编号】和【产品名称】外，其他项目基本信息不可在此修改。如需修改，请联系管理员。
```

---

### 错误示例2：非PM用户尝试修改

**用户指令**（来自非PM用户）：
```
把产品编号改成ABC-2026-001
```

**AI处理逻辑**：
1. 解析意图：类型A — 修改项目基本信息
2. 检查权限：`isPM=false`
3. 拒绝并回复：
```
❌ 权限拒绝：您非项目经理，只能查看数据。
```

---

### 错误示例3：缺少必需参数

**用户指令**：
```
把产品编号改成什么？
```

**AI处理逻辑**：
1. 解析意图：类型A — 修改项目基本信息
2. 提取参数：缺少 `productCode` 的新值
3. 追问确认：
```
请确认：您要将【产品编号】修改为什么值？
```
